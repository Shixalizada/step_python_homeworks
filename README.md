# STEP IT Academy Python Homework Project

Bu layihədə 3 ev tapşırığı bir VS Code Python project daxilində toplanıb.

## Fayllar
- `lesson2_hw.py` — funksiya, decorator, generator
- `lesson3_hw.py` — OOP I, Film kataloqu
- `lesson4_hw.py` — OOP II, Musiqi kolleksiyası
- `main.py` — hər dərsi ayrıca yoxlamaq üçün sadə menyu

## VS Code-da açmaq
1. ZIP faylını çıxart.
2. VS Code aç.
3. **File > Open Folder** seç.
4. `step_python_homeworks` qovluğunu aç.
5. Terminalda:
   ```bash
   python main.py
   ```

İstəsən hər tapşırığı ayrıca da işə sala bilərsən:

```bash
python lesson2_hw.py
python lesson3_hw.py
python lesson4_hw.py
```

Heç bir əlavə paket tələb olunmur.
